# 家长留言主题量度与联合复核

数据来自独立设计的合成业务记录，不含真实人员资料。文件为 UTF-8 JSON。

## 资料字典

每个 `frame` 是该期抽中的家庭，权重用于对该期家庭的估计；`responded` 是整户是否回访到，不是某主题的取值。`summaries` 同一 `session` 可由多渠道转写；`consent` 仅允许做反馈分析，内容本身不含可识别个人信息。`reviews` 逐人保存标签，只有符合当前词典且有明确共同定稿的标签才是已确认事实；`待合议` 不等同两人从未看过。`definitions` 给出主题列表和跨版关系；一对多表示不能确定子标签时不可复制父标签。`shift` 的 `capacity` 是每人每时段可以承担的会话数；`双语` 需要两名双语人员分别确认，同一个人不能重复填充两个复核位置。`approval` 给出历史、留出期及修订事实；`prebooked` 继续占用原站点会话名额，主题撤回日期后的主题不用于该口径的简报。未规定分类方法。
`editorial_budget` 为能选用的材料总费用上限；`editorial` 的 `all` 是同一家庭需要具有的全部主题，空列表不作为覆盖规则。多个材料覆盖同一符合条件家庭时只记一次。`editorial_floors` 表示各站点的最低覆盖率，分母为该站点抽样框加权人群，不因未回应或资料撤回缩小。`joint_review` 记部分共识与仍未决标签，不覆盖同一会话中其他的已确认标签。
`approval.holdout_households` 列整户不用于拟合的家庭；留出整期时还需排除该期本身。两个分离检验的适用范围各自记录。

## 读取与核对

使用 Python 3.11。
本地虚拟环境可按 `python3 -m pip install -r requirements.txt` 安装锁定的数值工具。有隔离运行环境时可直接使用已安装版本。

用 `python3 -m json.tool data/records.json` 查看原始记录。用 `python3 -m unittest discover -s tests -v` 核对演练资料的格式及关联。仓库目前只提供资料与输入核对，不提供业务分析结果。
