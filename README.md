# 家长留言主题量度与联合复核

数据来自独立设计的合成业务记录，不含真实人员资料。文件为 UTF-8 JSON。

## 资料字典

每个 `frame` 是该期抽中的家庭，权重用于对该期家庭的估计；`responded` 是整户是否回访到，不是某主题的取值。`summaries` 同一 `session` 可由多渠道转写；`consent` 仅允许做反馈分析，内容本身不含可识别个人信息。`reviews` 逐人保存标签，只有符合当前词典且有明确共同定稿的标签才是已确认事实；`待合议` 不等同两人从未看过。`definitions` 给出主题列表和跨版关系；一对多表示不能确定子标签时不可复制父标签。`shift` 的 `capacity` 是每人每时段可以承担的会话数；`双语` 需要两名双语人员分别确认，同一个人不能重复填充两个复核位置。`approval` 给出历史、留出期及修订事实；`prebooked` 继续占用原站点会话名额，主题撤回日期后的主题不用于该口径的简报。未规定分类方法。
`editorial_budget` 为能选用的材料总费用上限；`editorial` 的 `all` 是同一家庭需要具有的全部主题，空列表不作为覆盖规则。多个材料覆盖同一符合条件家庭时只记一次。`editorial_floors` 表示各站点的最低覆盖率，分母为该站点抽样框加权人群，不因未回应或资料撤回缩小。`joint_review` 记部分共识与仍未决标签，不覆盖同一会话中其他的已确认标签。
`approval.holdout_households` 列整户不用于拟合的家庭；留出整期时还需排除该期本身。两个分离检验的适用范围各自记录。

## 读取与核对

使用 Python 3.11。
本地虚拟环境可按 `python3 -m pip install -r requirements.txt` 安装锁定的数值工具。有隔离运行环境时可直接使用已安装版本。

用 `python3 -m json.tool data/records.json` 查看原始记录。仓库同时提供输入契约核对与完整业务分析，测试在隔离模式（`-I`）下也能直接发现：
`python3 -I -m unittest discover -s tests`（或 `python3 -I scripts/run_tests.py`）。

## 分析流水线（src/service_measure）

分析代码与数据目录分离，统一以隔离模式运行（不从数据目录加载代码）：

- 运行全部分析并写出 JSON 产物：
  `python3 -I scripts/run_analysis.py data/records.json outputs/analysis.json`
- 运行全部单元测试（含原输入契约测试）：
  `python3 -I scripts/run_tests.py`

### 模块与口径

| 模块 | 负责的业务口径 |
| --- | --- |
| `io.py` | 读取记录并校验输入契约（抽样框、摘要、复核、词典版本） |
| `taxonomy.py` | 词典时期版本、主题撤回、bridges 跨版关系；一对多只存疑不复制 |
| `facts.py` | 双人复核交集=确认事实；待合议保留部分共识；多渠道归并为一户一会话；未同意不分析；证据链可追溯 |
| `classifier.py` | 拟采用的小句证据判断器（交集学习、无证据弃权）与两个简单基准（冻结 v1 关键词、无时期全量关键词） |
| `evaluation.py` | 整户留出与整期留出两个分离检验；逐标签 F1、联合主题完全匹配/Jaccard、未决比例、加权占比偏差、硬拆错误 |
| `briefing.py` | 加权联合主题分布为主表；边际占比标注"不可相加"；未回访与未同意单列 |
| `editorial.py` | 材料组合并集覆盖（同户只记一次）、保守/乐观可证边界、站点最低覆盖缺口与不确定性来源、材料重叠矩阵 |
| `scheduling.py` | 站点/复核人容量、双语需两名不同复核人、prebooked 名额保留、按决策价值排下一批复核 |
| `pipeline.py` | 端到端编排，产物含 `decision_summary`（可正式采用 / 条件性可能 / 不满足及理由） |

### 关键判定规则

1. **一户一会话**：同一 session 的站点/回访转写归并，重复反馈不重复计数；多主题家庭一次保留多项主题。
2. **确认事实**：仅双人共同定稿标签的交集；待合议的交集仍有效，差集进未决；联合复核的部分共识不覆盖已确认事实。
3. **同意与回访**：未同意摘要不进入任何分析；未回访户没有会话事实，不等于"确证无障碍"。
4. **跨版标签**：旧标签仅在有足够已复核事实时才能用于新主题；一对多（时段→线上/现场时段）无法区分子标签时整体弃权，绝不两栏各记一份。
5. **留出评估**：整户留出（同版泛化）与整期留出（跨版泛化）范围各自记录；评估联合主题与未决比例，不只看逐标签正确率。
6. **材料决策**：同户多材料覆盖只记一次，组合按家庭并集核算；分母为站点整框权重（不因未回应缩小）；保守口径达标才可正式采用，乐观与保守之间只作为可证范围展示。
7. **排班**：双语会话须两名双语复核人分别确认；一户复核占一次案例容量；已约定复核不被取消；下一批按"能否改变材料决策"排序。
